# I.2B policy contract

Baseline: exact open PR #51 head `b237857a3ec21e4ba7a0cd13f8e0bcff3e58122d`, including accepted PR #50. Branch is `codex/115m-i-i-aud007-admission-policy`; the suggested `...-policy` name already belongs to PR #50 and is not modified. Resource policy is frozen at CONFIG.waveform, outside CONFIG.defaults and scene schema 10. Production load/seek/coordinator/extractor interfaces are unchanged and do not call this policy yet.

`validateWaveformPolicy(policy) → {ok, reason}` validates the whole source policy, including safe integral rates/counts/byte ceilings/probe limits, unique profile IDs, positive integral approximate minutes, resolvable default, and safe derived profile byte arithmetic. Zero hard budgets are valid explicit refusal ceilings; other numeric fields must be positive. Invalid values fail closed, with no fallback to unlimited or hidden factory ceilings. Expert-edited valid CONFIG values are honored. Unknown selected profile IDs resolve explicitly to the configured factory default. Unsupported request kinds refuse.

`resolveWaveformProfile(policy, selectedProfileId) → {id, approximateMinutes, pcmBytes, usedDefault}|null`. Profile workload uses minutes×60×configured output rate×2 reference channels×Float32Array.BYTES_PER_ELEMENT. Reference stereo is the product profile definition, independent of configurable unknown-channel fallback. It is not an absolute duration gate. Source profile edits govern both future label data and computed bytes.

`evaluateWaveformPolicy({fileSizeBytes, durationSeconds, channelCount, metadataConfidence, durationState, sourceSampleRateHz, selectedProfileId, requestKind, aboveProfileBehavior, headerMetadata}, policy=CONFIG.waveform) → decision` is pure: no File read, metadata probe, decode, AudioBuffer, resource slot, source/Queue/playback mutation or callbacks. It checks policy, positive safe whole File.size, encoded ceiling **before metadata interpretation**, normalized metadata/cost, PCM ceiling, then automatic profile. Inclusive equality is admitted. Returns `{decision, reason, profileId, profilePcmBytes, estimatedPcmBytes, metadata}` as available. Outcomes: admit/within-budget; offer/above-auto-profile; defer/metadata-pending; refuse/encoded-budget, pcm-budget, metadata-unavailable, invalid-policy, invalid-file-size or invalid-request. Metadata carries confidence/assumptions; unsafe arithmetic refuses with pcm-budget plus invalid estimate detail. Automatic above-profile behavior defaults to source-configured ask: offer. generate-if-permitted admits after both hard ceilings pass; skip refuses this automatic request with above-auto-profile and manualEligible true. Manual bypasses only the convenience profile, never either hard ceiling. These accepted choices are pure inputs, not UI/persistence/integration. No decision implies a guaranteed native-memory upper bound.

The metadata module separately interprets supplied values and optionally probes bounded PCM WAV headers. Duration state is pending, available or unavailable. A missing/NaN duration with pending state defers; absent unavailable state refuses; negative/zero/infinite or malformed available duration refuses. A supplied invalid channel value is not treated as missing. Verified information missing required dimensions or contradicting other verified information is invalid, never replaced by a smaller assumption. Known duration with unknown channels uses CONFIG fallback count with explicit estimated confidence. Analysis similarity/playback output channels are not inputs.

I.2C must consume the decision before optional full read/native decode, associate metadata with the current File/media identity, remove stale listeners, revalidate manual requests/changed metadata and invoke the unchanged single-flight coordinator only after admit. offer/defer/refuse must not reserve its native slot. Future application choices/persistence are outside scene presets. This phase neither implements that bridge nor reduces automatic waveform availability. Native diagnostic callers invoke the pure policy directly and compare decisions with independent playback and actual decode dimensions.

The encoded-before-read negative control injects a forbidden full read before the gate into a disposable policy copy; it tests purity/order without claiming I.2C integration exists. Other controls exercise PCM hard refusal, manual ceiling, false confidence, absolute-duration interpretation, ignored source overrides and unsafe inputs.

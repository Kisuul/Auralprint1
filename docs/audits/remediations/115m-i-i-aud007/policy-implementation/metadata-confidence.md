# Metadata and cost confidence

`interpretWaveformMetadata(input, policy)` is pure. Input uses the decision-contract fields and optional `headerMetadata` from the probe. Output is verified, estimated, unknown or invalid; successful estimates include duration, channels, source sample rate if known, assumption, ceil-rounded configured-output frames and estimated Float32 bytes. Unknown duration is pending/defer or unavailable/refuse. Malformed/infinite/negative/zero duration, malformed supplied channels, unsafe arithmetic and contradictory metadata are invalid. Missing channels are distinct from invalid channels.

Known duration with no channel metadata uses CONFIG.waveform.fallbackEstimatedChannels (factory 2), `confidence: estimated`, `assumption: configured-channel-fallback`. Even when that happens to equal actual native output, the assumption remains estimated. A supplied unverified channel count is also estimated. AnalysisFrame mono/stereo similarity, AudioEngine output channels and downmixed analyser results are never consulted. Verified channel metadata missing required dimensions is refused; it cannot fall through to a smaller fallback.

`inspectPcmWavHeader(prefixArrayBuffer, fileSizeBytes, metadataProbe)` is pure and performs no IO. `probeWaveformMetadata(file, policy)` is an explicit asynchronous bounded adapter. It checks positive safe File.size and the encoded ceiling before invoking File.slice. A bounded slice may contain an entire small File; it never invokes the unbounded File.arrayBuffer waveform path. One prefix read is at most CONFIG metadataProbe.maxBytes (factory 65,536); chunk traversal is at most maxChunks (factory 128). Invalid probe policy or oversized input starts no probe. Probe IO is separate from full waveform extraction and never calls decodeAudioData/coordinator. I.2B contains no production caller. I.2C will own current-request/probe lifetime and identity; no scheduler/cache/listener subsystem is introduced here.

Supported verified layouts: little-endian RIFF/WAVE, classic integer PCM (format 1) or PCM extensible (65534 with PCM GUID, valid bits and consistent optional channel mask), container widths 8/16/24/32, one valid fmt followed by terminal data. Declared RIFF size must match File.size; every inspected chunk offset/length/pad must fit; byte rate/block alignment must match rate/channels/width; data must contain integral nonzero frames. Header-derived duration is data frames/source sample rate. Supplied verified channels/source rate or available media duration that disagree invalidate metadata. Media/header tolerance is one frame at the slower source/configured output rate to allow native resampling rounding, not an arbitrary admission grace period.

If a supported fmt is already known when traversal/prefix budget runs out, its channel/rate fields survive as estimated partial-header information; supplied media duration can then estimate cost without reverting six known channels to stereo. RF64/RIFX, non-WAVE containers, compressed/float WAV, unsupported PCM widths, data-before-fmt/nonterminal-data layouts, missing data and headers beyond prefix/work budget remain explicitly unverified. MP3/Ogg are not parsed. They can use known media duration and explicit estimated channel fallback. Recognized malformed/contradictory supported WAV returns invalid and is never silently replaced by a stereo estimate. A structurally verified header is not a proof of decoded content or native scratch size; arbitrary media/browser behavior can still fail or differ.

Decoded output estimate is ceil(duration×configured output rate)×channels×Float32Array.BYTES_PER_ELEMENT. Source rate can increase temporary native source PCM/resampling cost even when returned output is 44.1kHz. Returned AudioBuffer dimensions are post-allocation diagnostic observations, not pre-decode hard memory bounds. The configured PCM ceiling bounds the estimate, not every physical buffer. Source ceilings are provisional and expert edits can increase risk; concurrency remains enforced by the unchanged I.2A coordinator regardless of these values.

The waveform governor bounds admitted optional jobs, encoded input size and estimated decoded workload. It does not guarantee total browser memory consumption. Removing its admission checks would reintroduce AUD-007's unbounded optional-work exposure.

In I.2B, the new decision/probe modules are tested but restrictive production activation is deferred to I.2C. Normal automatic waveform availability remains unchanged. Native compressed formats actually demonstrated, their assumptions/output comparisons, and unsupported/unknown cases are listed in the README and evidence; no generic compressed-codec support claim is made.
